# Portfolio — Noé Bardin

Site statique (HTML / CSS / JS), hébergé sur GitHub Pages.

- `index.html` : structure des sections
- `style.css` : direction artistique (couleurs et typos en haut du fichier)
- `main.js` : `CONFIG` (mail, LinkedIn, CV) et `PROJECTS` (les travaux du studio) en haut du fichier
- `assets/` : images et vidéos compressées

Ajouter un projet : déposer le média dans `assets/`, puis ajouter un objet à `PROJECTS` dans `main.js`.
